# 1D Kalman Filter from Scratch

A lightweight, well-tested implementation of a one-dimensional Kalman filter in Python. Built for educational clarity and robustness, with extensive validation against edge cases.

## Key Features
✅ **Pure Python** – Zero dependencies, easy to integrate  
✅ **Educational Focus** – Clean, commented code for learning  
✅ **Stress-Tested** – Validated against extreme scenarios:
   - Massive noise (`variance = 10,000`)  
   - Near-perfect sensors (`variance = 0.00000001`)
